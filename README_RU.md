# Tender AI 2.0 — стартовая рабочая сборка

Это минимальное ядро, которое можно развернуть на Render.

## Что уже есть
- Telegram-бот;
- `/start`;
- обычный диалог с ИИ;
- кнопки `УЧАСТВУЕМ / НЕ УЧАСТВУЕМ / ГЛУБОКИЙ АНАЛИЗ`;
- webhook для Render;
- `/health` для проверки сервиса;
- конфигурация `render.yaml`.

## Что будет следующим модулем
1. PostgreSQL / Supabase.
2. Карточка тендера.
3. Tender Workspace.
4. Память по каждому тендеру.
5. Загрузка PDF/XLSX.
6. Расчёт экономики и стоп-цены.
7. Поставщики.
8. Автоматический мониторинг закупок.
9. Каскад моделей для снижения стоимости API.

## Секреты
Никому не отправляй:
- TELEGRAM_BOT_TOKEN
- OPENAI_API_KEY

Их нужно вставлять только в Environment Variables на Render.
